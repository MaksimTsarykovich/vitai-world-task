## 3.1. Производительность (Lighthouse mobile, прод-сборка)

| Метрика | Значение | Цель в спеке |
|---|---|---|
| performance | 92–95 (прогоны: 92, 93, 94, 95) | ≥ 90 ✅ |
| accessibility | 100 | ≥ 95 ✅ |
| best-practices | 77 | ≥ 95 ❌ (сторонние cookie Яндекс.Карт) |
| SEO | 100 | 100 ✅ |
| LCP | 2.8–3.2 с в симуляции slow 4G | < 2.5 с ❌ |
| FCP | 1.2 с | — |
| CLS | 0 | < 0.1 ✅ |
| TBT | 50–130 мс | < 200 мс ✅ |
| вес страницы | 4.8 МБ | — |

Разбор отклонений. Встроенная Яндекс.Карта ставит сторонние cookie и грузит тайлы
(4.8 МБ против 339 КБ без них) — отсюда `best-practices` 77. Это осознанный
компромисс по требованию заказчика: карта должна быть видна сразу, без кнопки.
Вариант без потерь: подгружать `<iframe>` при приближении к секции
(IntersectionObserver с запасом ~300 px) — карта появляется сама, сторонние ресурсы
не участвуют в первой загрузке. Готовы переключить, если приоритет — оценки.

LCP в симуляции выше цели из-за тех же тайлов карты: замер идёт с троттлингом
slow 4G (×4 CPU). В обычном браузере LCP-элемент (hero-фото в AVIF, 25 КБ)
отрисовывается за ~0.35 с при TTFB 14 мс. Отдельно: первый прогон сразу после
пересборки контейнера дал 79 и LCP 3.9 с — это холодный старт, на прогретом
сервере три прогона подряд дают 93–95.

Числа сняты с текущей сборки (после перехода базы на libSQL): изменился только
серверный слой, клиентский бандл тот же, что давал те же оценки раньше.

Ссылка на живой сайт по ТЗ должна открываться с реальной картой, так что текущий
вариант корректен по задаче; цифры выше сняты с этого состояния.

## 7. Как переснять Lighthouse на живом сайте

Замер в репозитории снят с прод-сборки в контейнере (`localhost:3000`). После деплоя
полезно повторить на боевом адресе — метрики сети будут другими:

```bash
CHROME_PATH=/usr/bin/google-chrome npx -y lighthouse@13 https://ваш-домен \
  --only-categories=performance,accessibility,best-practices,seo \
  --form-factor=mobile --throttling-method=simulate \
  --chrome-flags="--headless=new --no-sandbox" \
  --output=json --output=html --output-path=artifacts/lighthouse/mobile-live --quiet
```
