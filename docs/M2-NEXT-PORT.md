# M2: перенос макета в Next.js (issue #23)

Задача: превратить финальный статический макет в настоящую страницу приложения —
Next.js 16 (App Router, RSC) в каталоге `web/`, скомпилированный Tailwind 4, без
браузерной сборки Tailwind и без внешних CDN-скриптов.

**Эталоны, менять нельзя:**

- `artifacts/design/index.html` — финальный макет: разметка, тексты, классы, детали.
- `artifacts/design/tokens.html` — палитра, радиусы, типографика, состояния полей,
  свитчера и режимов формы.

**Процесс:** работай прямо в `web/`. Не снимай скриншоты, не запускай headless-браузер
(визуальную приёмку делает заказчик), не создавай копии файлов в `/tmp`, не коммить —
изменения оставляй в рабочем дереве и отчитайся в конце.

## 1. Токены и стили

1. `web/app/globals.css`: оставить `@import "tailwindcss"` и перенести в `@theme`
   токены из макета: цвета `paper #F2EBDD`, `cream #E4D8C3`, `ink #221A15`,
   `espresso #3B2A20`, `stamp` и его тёмный вариант для мелкого текста,
   `olive #6F7459`; радиусы `--radius-sm 6px`, `--radius-md 10px`, `--radius-lg 16px`;
   шрифтовые переменные.
2. Перенести из макета вспомогательные утилиты: бумажную текстуру (`paper-grain`),
   пунктирную линию (`rule-dotted`), круглый штамп (`stamp-mark`), стили свитчера
   (`switch-input/track/knob`), `tnum`, `prefers-reduced-motion`, `:focus-visible`.
3. Шрифты — через `next/font/google`: Literata (display) и Manrope (текст/UI),
   `subsets: ['cyrillic', 'latin']`, `display: 'swap'`, CSS-переменные
   `--font-display` / `--font-sans`. Внешние `<link>` на Google Fonts в разметке не
   оставлять.

## 2. Компоненты

4. `web/components/ui/`: `Container`, `SectionLabel` (подпись + номер секции),
   `Button` (primary/secondary), `Switch` (доступный переключатель на скрытом
   чекбоксе, как в макете), `Stamp`.
5. `web/components/sections/`: `Header` (липкая тёмная шапка, якоря, мобильное
   меню), `Hero` (фото слева, текст справа, плашка «Ближайшая обжарка» одной
   строкой), `KtoMy` (кто мы), `Assortment` (4 позиции с ценами), `Zayavka`
   (форма на тёмной подложке + строка про доставку «развозим в пятницу, от 50 BYN —
   бесплатно»), `Kontakty` (Яндекс.Карта, адрес, часы, телефон, соцсети), `Footer`.
6. `web/components/form/`: `LeadForm` (клиентский, режимы «вопрос»/«заказ»),
   `OrderTable` (Наименование / Кол-во / Сумма + «Итого», повторное добавление
   увеличивает количество, `−`/`+`, удаление), `InterestSelect`.
7. Данные вынести из разметки: `web/lib/products.ts` (slug, название, нота, вес,
   цена — 32/29/26/18 BYN), `web/lib/site.ts` (адрес Минск, ул. Короля 9, часы
   пн–пт 8:00–20:00 · сб–вс 10:00–18:00, телефон, e-mail, Telegram, Instagram,
   пометка «данные тестовые», порог бесплатной доставки 50 BYN).
8. Дату ближайшей обжарки считать на сервере (ближайший четверг, `Europe/Minsk`) в
   `web/lib/roast-date.ts`; страница обновляется не реже раза в час.

## 3. Форма

9. Селект «Что интересует»: пустая опция по умолчанию + «У меня есть вопрос»
   (`question`) и «Хочу сделать заказ» (`order`).
10. Режим «заказ»: свитчер «Оформить подписку — 54 BYN/мес, 2 пачки по 250 г,
    доставка бесплатно», селект сорта (обязателен), кнопка «Добавить сорт»,
    таблица заказа; комментарий видим и необязателен.
11. Режим «вопрос»: только комментарий, он обязателен; сорт, кнопка и свитчер
    скрыты через `hidden`; `required` переключается динамически, чтобы скрытые поля
    не блокировали отправку.
12. Состояния: ошибки обязательных полей (под полем, `aria-invalid`,
    `aria-describedby`, фокус на первом невалидном), отправка с блокировкой кнопки,
    успех, дубликат, ошибка сети с «Попробовать ещё раз» — как в макете.
13. Отправка: единая функция `submitLead()` в `web/lib/lead-client.ts`, которая
    собирает payload (имя, телефон, интерес, комментарий, сорта с количеством,
    флаг подписки) и пока вызывает заглушку, помеченную `TODO(#24): POST /api/lead`.
    Реальный эндпоинт появится в задаче #24 — интерфейс функции не менять.

## 4. Фото, карта, метаданные

14. Скачать фото из макета (те же Unsplash-кадры) в `web/public/images/` понятными
    латинскими именами (`hero-beans.jpg`, `about-holder.jpg`, `ethiopia.jpg`,
    `colombia.jpg`, `brazil.jpg`, `drip.jpg`, `delivery-boxes.jpg`) с разумным
    размером (до ~300 КБ на файл), подключить через `next/image` с `width`/`height`,
    `sizes` и `alt` из макета.
15. Лицензии: `artifacts/issues/23-landing/licenses.md` — имя файла, ссылка на
    кадр, фотограф (взять со страницы фото; если не удалось — пометить
    «автор уточняется»), лицензия Unsplash.
16. Яндекс.Карта: `<iframe>` с `https://yandex.by/map-widget/v1/?text=…&z=17`,
    `loading="lazy"`, `title`, скругление — как в макете, плюс запасная ссылка
    «Открыть в Яндекс.Картах».
17. Метаданные: `title`/`description` из макета, `metadataBase` из `SITE_URL`
    (переменная уже есть в `lib/env.ts`), `lang="ru"`. OG-картинку не делать — это
    задача #25.

## 5. Чего не делать

- Не менять `web/lib/db.ts`, `web/app/api/health/route.ts`, `web/Dockerfile`,
  `compose.yaml` (кроме случая, когда сборка требует правки — тогда объясни в отчёте).
- Не трогать `artifacts/design/**` — это эталон.
- Не подключать Tailwind через CDN, не тащить UI-киты, иконочные шрифты, анимационные
  библиотеки, не добавлять ORM.
- Не оставлять на странице технические надписи, эмодзи и заглушки вида «каркас M1».
